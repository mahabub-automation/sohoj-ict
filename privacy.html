Privacy Policy

Sohoj ICT Uploader · Last updated: 12 October 2026

Sohoj ICT Uploader ("the app") is a private tool operated by the owner of the Sohoj ICT YouTube channel (@sohojict). It is used only by the channel owner to upload educational videos to that channel. It is not offered to the public.

What the app accesses

With the channel owner's permission, the app uses the YouTube Data API to:

  • upload videos to the Sohoj ICT channel (scope: youtube.upload), and
  • read the basic channel name and ID, only to confirm the correct channel is connected (scope: youtube.readonly).

What data is stored

The only data stored is the OAuth access/refresh token for the owner's own channel. It is kept in a private file on the owner's server and is never sold, shared or sent anywhere except to Google's APIs. The app does not collect any data about viewers or any other users.

YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be removed at any time from the Google account security page: myaccount.google.com/permissions. When access is revoked, the stored token stops working and is deleted.
